# Pasanaku
Sistema web destinado a la creación, administración y seguimiento de grupos de pasanaku.

## Documentación

- **[docs/entidades/](docs/entidades/README.md)** — modelo de datos completo. Para cada
  uno de los 9 módulos hay un `.puml` (modelo de clases + modelo relacional) y un
  `.md` que documenta **qué hace cada entidad y por qué debería existir**: qué
  problema real del pasanaku resuelve, qué se rompería si se elimina, y qué papel
  cumple en el sistema.
